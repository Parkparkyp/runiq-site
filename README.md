# 루닉필름 홈페이지 (runiq.kr)

정적 사이트예요. 빌드 도구 없이 파일만 올리면 돼요.

## 파일
- `index.html` 소개 · `work.html` 작업 · `price.html` 상품·가격 · `faq.html` FAQ · `review.html` 후기(없으면 메뉴 숨김)
- `site.js` **여기만 고치면 돼요** (링크, 금액, 문구, 영상·사진 목록)
- `assets/` 사진·영상 파일을 넣는 폴더
- `style.css` 모양, `run.js` 동작 (보통 안 건드려요)
- `CNAME` 연결할 주소(runiq.kr)

## 올리는 순서 (처음 한 번)
1. GitHub에서 새 저장소 `runiq-site`를 만들어요. (Public)
2. 이 폴더 안의 파일을 전부 올려요. (`assets` 폴더 포함)
3. 저장소 Settings > Pages > Source: `Deploy from a branch`, Branch: `main` / `/(root)` 저장
4. Custom domain에 `runiq.kr` 입력 후 저장, 잠시 뒤 `Enforce HTTPS` 체크
5. DNS는 이미 맞춰져 있어요. (`@` A 레코드 4개, `www` CNAME → `parkparkyp.github.io.`)
   - 주의: 이 저장소를 올리기 전에는 `runiq.kr`가 빈 곳을 가리켜요. 올리고 나서 Custom domain을 설정하세요.
6. 앱(`my.runiq.kr`)과는 별개의 저장소라 서로 영향이 없어요.

## 공개하기 전에 (중요)
지금은 검색에 안 잡히게 막아 뒀어요.
- 각 html의 `<meta name="robots" content="noindex">` 줄
- `robots.txt`의 `Disallow: /`
→ 내용이 다 채워지면 "공개해도 돼"라고 알려 주세요. 제가 두 곳을 풀어서 드릴게요.

## 채워야 하는 것 (`site.js`)
- `book`: 앱 설정 > 예약신청의 링크를 "🔗 복사" 해서 붙여넣기. **비어 있으면 예약 버튼이 숨겨져요.**
- `kakao`, `instagram`, `youtube`, `blog`: 비어 있으면 해당 버튼이 숨겨져요.
- `heroVideo`(+`heroPoster`): 첫 화면 영상. `assets/hero.mp4` 처럼 넣고 경로를 적어요. 20초 안팎·소리 없는 영상을 권장해요.
- `principle`: 촬영 방침 한두 줄. `notice`: 상품 페이지의 "꼭 확인해 주세요".
- `work`: `{img:'assets/w1.jpg'}` 또는 `{yt:'유튜브영상ID'}`
- `reviews`: 후기 캡처 이미지 경로. 비어 있으면 "후기" 메뉴가 숨겨져요.
- `price`: 앱의 금액 설정과 같은 값으로 맞춰요.

## 사진 올릴 때
- 가로 1600px 안팎, JPG, 한 장 500KB 이하로 줄이면 빨라요.
- 영상 파일은 GitHub 용량 한도가 있어서 파일당 25MB 이하를 권장해요. 큰 영상은 유튜브 링크로 넣으세요.
- 포트폴리오 활용 동의를 받은 고객 것만 올리세요.

## 관리 페이지 (admin.html) — 폰에서 홈페이지 고치기
`https://runiq.kr/admin.html` 에서 링크·영상·문구·금액을 바꾸면 홈페이지에 반영돼요 (최대 10분).
서버는 **예약 앱과 완전히 별개**인 Apps Script 프로젝트예요 (고객 정보 없음).

### 서버 설치 (한 번만) — `homepage-server-Code.gs` 파일
1. script.google.com 에서 **새 프로젝트**를 만들고 이름을 "루닉 홈페이지 설정"으로 바꿔요. (예약 앱 프로젝트가 아니에요!)
2. 기본으로 있는 코드를 전부 지우고 `homepage-server-Code.gs` 내용을 붙여넣어요.
3. 맨 위 `const SECRET = '…'` 의 따옴표 안을 **길고 아무도 모르는 글자**(20자 이상, 영문·숫자 섞기)로 바꿔요. 이 키는 채팅·GitHub에 올리지 말고 비밀번호 관리자나 메모에만 적어 두세요.
4. 저장(Ctrl+S) 후 오른쪽 위 **배포 > 새 배포** > 유형 ⚙️ **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자** (홈페이지 방문자가 읽어야 해서 꼭 이렇게)
   - 배포를 누르고 권한 승인 → 나오는 **웹 앱 URL**(…/exec)을 복사해요.
5. 이 URL을 `site.js`의 `api: ''` 에 넣어야 해요. (채팅으로 보내 주시면 제가 넣어 드려요. 이 URL은 공개돼도 되고, 비밀인 건 SECRET뿐이에요.)
6. `runiq.kr/admin.html` 에 접속 > 비밀키 입력 > 불러오기 > 값 입력 > 저장.
7. 폰 크롬에서 admin.html을 열고 메뉴(⋮) > **앱 설치** 또는 **홈 화면에 추가**를 눌러요. 홈 화면에 "홈페이지 관리"(루 아이콘)가 생기고 앱처럼 열려요.

### 알아 둘 것
- 비밀키를 8번 틀리면 15분간 잠겨요 (홈페이지 표시에는 영향 없음).
- 서버가 안 되는 날에도 홈페이지는 `site.js`의 값으로 정상 표시돼요.
- 서버 코드를 고치면 배포 > 배포 관리 > 연필 > 버전 "새 버전"으로 다시 배포해야 해요.
- `admin.html` 은 검색에 노출되지 않게 막아 뒀어요. 주소를 남에게 알려 주지 마세요.

### 대문(첫 화면) 영상
- 관리 페이지의 "대문(첫 화면) 영상"에 유튜브 링크를 넣으면, 소개 페이지 맨 위 화면에서 **소리 없이 반복 재생**돼요. 화면을 꽉 채우려고 위아래/좌우가 잘려 보일 수 있어요.
- 처음에는 영상 썸네일 사진이 보이다가 재생이 시작되면 영상으로 바뀌어요.
- 아이폰 절전 모드, 데이터 절약 모드, "움직임 줄이기" 설정에서는 영상 대신 썸네일 사진이 보여요. (정상이에요)
- "▶ 소리 켜고 영상 보기"를 누르면 소리 있는 영상 창이 떠요.
- 영상은 "공개" 또는 "일부 공개"이고 퍼가기 허용이어야 해요. 짧고(20~60초) 화면 중앙에 볼거리가 있는 영상이 잘 어울려요.

### v2 변경 (대문·가격 페이지)
- "소리 켜고 영상 보기" 버튼을 없앴어요. 영상은 컨트롤 없이 재생만 돼요.
- 상품·가격 페이지 맨 위 배경에 **인터뷰 영상 1개**가 소리 없이 반복 재생돼요. (관리 페이지 > "상품·가격 페이지 배경 영상")
- 예약신청서 버튼은 상품 카드 바로 아래에 있어요.
- 관리 페이지 "멘트"에서 대문 제목·한 줄 소개, 상품·가격 제목·설명을 고칠 수 있어요. 칸을 비우고 저장하면 기본 문구로 돌아가요.
- **서버 코드(homepage-server-Code.gs)가 바뀌었어요.** Apps Script에 다시 붙여넣고 SECRET만 기존 값으로 다시 적은 뒤, 배포 > 배포 관리 > 연필 > 버전 "새 버전"으로 재배포해야 새 항목이 저장돼요.

### v3 변경 (가운데 정렬 · 대표 사진 · 로고 · FAQ 페이지 · 모든 멘트 수정)
- 모든 문구(대문, 소개, 진행 순서, 상품 카드 내용, 할인·추가 비용, FAQ 질문·답, 하단 문구, 버튼 글자)를 **관리 페이지에서 수정**해요. 목록은 추가·삭제·위아래 이동이 돼요. 칸을 비우면 그 부분이 숨겨져요.
- 문구에 `{total} {deposit} {portfolio} {full}` 을 쓰면 금액으로 자동 바뀌어요. (예: 계약금 {deposit})
- "예약" 메뉴·페이지는 없앴어요. 예약 버튼은 예약신청서(`book` 링크)로 바로 가요. FAQ가 별도 메뉴예요.
- 대표 사진은 `assets/owner.jpg`, 로고는 `assets/logo.png`(갈색)·`logo-white.png`(흰색)이에요. 사진을 바꾸려면 같은 이름으로 GitHub에 덮어써서 올려요.
- "관리 페이지 > 모든 문구를 기본 문구로 되돌리기" 후 저장하면 처음 문구로 돌아가요.
- **서버 코드(homepage-server-Code.gs)가 바뀌었어요 (hp-v3).** Apps Script에 다시 붙여넣고 SECRET만 기존 값으로 적은 뒤, 배포 > 배포 관리 > 연필 > 새 버전으로 재배포해야 저장돼요. (재배포 전에는 새 항목 저장이 거부될 수 있어요.)
